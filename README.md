# GoDoStuffKIDS

City adventure guides for families. Real places, real exploration, real fun.

**Live at:** https://mariavheland.github.io/godostuffkids/

## Cities
- 🇩🇪 Berlin — 103 entries, 9 themes, full quiz system
- 🇳🇱 Amsterdam
- 🇫🇷 Paris
- 🇸🇪 Stockholm

## What it is
GoDoStuffKIDS is a standalone sister product to [GoDoStuff](https://github.com/MariavHeland/godostuff). It's not a filtered version of the adult guide — it's a different product written for families, with:
- Age filtering (ages 3–14)
- Nine adventure themes (Water, Wild, Stories, Make, Move, Discover, Grow, Rescue, Navigate)
- Quizzes that only work if you were actually there
- Honest parent tags (bring spare socks / stroller hell / best before 11am)
- Language toggle (local language / English)

## Architecture
Each city is a standalone HTML file with everything bundled. No build step, no dependencies, no server required.
